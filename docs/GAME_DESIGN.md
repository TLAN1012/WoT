# 南方祖記 — 英雄戰棋設計

## 方向

RPG 型態的六角格英雄戰棋。一格一位英雄,每位英雄有職業、五項屬性、等級、點數與技能;從(假想的)冰河時期開始,一群人跨海東來,最後成為馬卡道人——高雄人的始祖。

- 畫風致敬《魔法公主》:手繪賽璐璐、水彩背景,和紙色介面。美術全部由自架畫室(Qwen-Image)生成,腳本 `scripts/art/gen-art.py`。
- 手機優先:全螢幕地圖、拖曳縮放、底部英雄列與技能列。
- 舊版十關(七千年前、Phaser)保留在 `legacy/`,部署在 `/WoT/legacy/`,之後會重做成較後面的章節。

### 祖名傳承

跨入新的一代時(章節的 `generation`),後代承襲祖先的名字與職業系:等級保留一半(至少 2)、經驗歸零、自由點數全部退回重新分配;信物、足跡、名冊都保留。
外表換成那一代的樣子(`portraits/<id>-g2.webp`),同伴畫面的介紹也換成承名者的故事。
許多台灣原住民族有承襲祖父母名字的傳統,這是設計的出發點。

### 漲潮

`tides`:某回合開始時一批格子變成淺灘、下一波變成海;站在被淹格子上的人被浪推上最近的陸地(不會淹死)。
「海漲」一戰要在海水追上之前,讓所有人登上東邊的珊瑚礁台地。

## 規則

### 回合

我方階段 → 敵方階段。每位英雄每回合可「移動一次 + 行動一次」;行動(技能、普攻、待命)後不能再移動。走進敵人相鄰的格子(控制區)就得停下。友軍可以穿過、不能同格。

### 屬性 → 數值

| 屬性 | 影響 |
|---|---|
| 力 str | 物攻 = 力 × 2 |
| 敏 agi | 暴擊率 = 敏 × 1.5%(上限 40%);獵手系的物攻 + 敏 |
| 智 int | 法術 = 智 × 2;靈力上限 + 智 |
| 靈 spi | 治療 = 靈 × 2;抗性 = 靈 + 智/2;靈力上限 + 靈 × 2;每回合回靈 2 + 靈/3;祭司的法術 + 靈 |
| 體 vit | 生命 = 20 + 體 × 6;防禦 = 體 + 職業護甲 |

屬性 = 職業基礎 + 每級自動成長 ×(等級 − 1)+ 自由點數。每升一級得 3 點自由點數,可以在「同伴」畫面分配、重置。每 100 經驗升一級,上限 10 級。

### 傷害

```
傷害 = 攻擊力 × 技能威力 × 30 / (30 + 防禦或抗性) × 修正
修正:狂血(生命越低最多 +40%)、強化 +30%、鬣狗包圍(每隻相鄰同伴 +20%,最多 +40%)
      × (1 − 地形承傷修正) × 守勢 0.7 × 圖騰 0.8 × 祖靈庇佑 0.9 × 難度
暴擊 ×1.5(法師系法術 ×1.75)
```

### 資源

- 怒氣(Kapah、Hanup):開場 20,出手命中 +15、受傷 +10,上限 100。
- 靈力(Inibs、Vukid、Rikat、Hanitu):開場全滿,每回合回復。

### 技能形狀

單體、弧斬(前方三格)、旋風(身邊一圈)、直線貫穿、範圍爆炸、連鎖跳躍、直線衝撞(擊退)。

### 狀態

暈眩(跳過一回合)、遲緩(移動 −2)、強化、守勢、挑釁(只能打施放者)、再生。減益在自己回合結束時 −1,增益在自己回合開始時 −1。

### 地形

凍原、積雪、冰面(承傷 +15%)、玄武岩台地(承傷 −20%、遠程射程 +1)、針葉林(−25%)、淺灘、凍沼、海、亂石、營火(每回合回 15% 生命、寒祟不能進入)。

### 勝敗與評價

勝利條件:擊退全部、撐過 N 回合(或擊退首領)、淨化神獸。三人全倒 = 失敗(敗北仍保留一半經驗)。
★ 勝利 ★ 沒有人倒下 ★ 在標準回合內。

## 相剋

五種戰型繞成一圈,每一型剋下一型、被上一型剋(剋制傷害 ×1.35、被剋 ×0.8),其餘不相干:

```
斧 → 獸 → 弓 → 靈 → 巨 → 斧
```

| 戰型 | 誰 |
|---|---|
| 🪓 斧 | Kapah(巴度) |
| 🐾 獸 | 鬣狗、灰牙、雪紋虎 |
| 🏹 弓 | Hanup(瑪塔) |
| ✨ 靈 | Inibs(達努)、Rikat(比杜)、Hanitu(布蘭)、寒祟、靈鹿 |
| ⛰️ 巨 | Vukid(卡西)、古象神 |

戰場上每個單位左下有戰型圖示;出手預覽會標「剋制▲/被剋▼」;頂欄 ☯ 打開相剋圖。

## 布陣與上陣名額

開戰前是布陣階段:出發區(藍色格子)內自由換位置;名冊比名額多時可以換人上場。離岸 3 人,之後 4 人。
沒上場的候補在勝利時拿一半的勝利經驗。

## 收集英雄

村裡其他孩子沿著三人的記號追過陸橋。戰鬥中撿到他們的足跡,集滿 6 個就能在「同伴」畫面招募(以同伴平均等級加入,點數可以自己分配)。

| 英雄 | 名字 | 職業 | 戰型 | 足跡來源 |
|---|---|---|---|---|
| 瑪塔 | Mata *maCa「眼睛」 | Hanup 追跡獵手:穿雲箭、獵人標記、釘足箭 | 弓 | 離岸首勝 4、玄武岩首勝 2、重玩 |
| 卡西 | Kasiw *kaSiw「樹」 | Vukid 林之子:藤縛、化熊、林癒 | 巨 | 玄武岩首勝 3、寒祟古象首勝 3、重玩 |
| 布蘭 | Bulan *bulaN「月亮」 | Hanitu 月下靈語者:靈鹿、安魂、靈縛;在場時看得見野獸下一步撲向誰 | 靈 | 寒祟古象首勝 3、重玩 |

## 信物

每位英雄身上有三個配戴位置,同一件信物戴在不同位置,發揮不同的力量:

| 位置 | 代表 | 方向 |
|---|---|---|
| 額 | 神識 | 看穿、專注(暴擊、免耗、冷卻) |
| 胸 | 信念 | 守護、意志(落空、守勢、免控) |
| 臍 | 生命 | 復甦、體魄(復活、再生、生命上限) |

來源:每場戰鬥第一次勝利的獎勵(勝利畫面會展示插圖與由來);戰鬥中擊倒野獸時隨機掉落,勝利才帶得走。

| 信物 | 來源 | 額 | 胸 | 臍 |
|---|---|---|---|---|
| 鬣狗之首 | 離岸首勝、鬣狗 6%、灰牙 50% | 第一擊必定暴擊 | 一次攻擊落空(40%) | 倒下時以 5% 生命站起 |
| 六角石片 | 玄武岩之夜首勝 | 第一次施放不耗資源 | 開場守勢 2 回合 | 每回合回 5% 生命 |
| 古象神的祝福 | 寒祟古象首勝 | 技能冷卻 −1 | 免疫暈眩、遲緩 | 生命上限 +15% |
| 寒祟冰晶 | 寒祟 12% | 法術傷害 +10% | 第一次被打時讓攻擊者遲緩 | 法術承傷 −15% |
| 雪紋虎的爪 | 雪紋虎 60% | 對半血以下 +20% | 移動 +1 | 擊倒時回 10% 生命 |

## 難度

溫和(野獸 −15%、可悔棋)/ 勇者 / 傳說(野獸血 +25%、傷害 +20%、AI 最精明)。

## 平衡

`BALANCE=1 N=20 npx vitest run src/game/__tests__/balance.test.ts` 讓模擬玩家對打三個難度,並依平均經驗推進等級。
模擬玩家比真人精準,勝率只當下限參考,以真人試玩回饋為準。

## 配樂

全部由自架 ACE-Step 1.5 生成(nb395p,`~/ace-step/wot_bgm_batch.py`,曲目描述在 `src/audio/music.ts`),每個段落兩首不同風格:

| 段落 | A | B | 自動選曲 |
|---|---|---|---|
| 主題曲 | 吉卜力管弦 | 日本陽音階(尺八、箏) | 標題、地圖、同伴 |
| 劇情 | 陶笛與拇指琴 | 洞簫獨奏 | 戰前戰後用 A,序章與終章用 B |
| 戰鬥 | 太平洋島嶼打擊樂 | 太鼓與尺八 | 離岸 A、玄武岩之夜 B |
| 首領戰 | 黑暗史詩合唱 | 原始吟唱與大鼓 | 寒祟古象 A |
| 勝利 / 撤退 | 管弦 / 長笛 | 吟唱 / 箏與尺八 | A |

玩家可在「音樂室」試聽並把任一段固定成 A 或 B。循環曲約 2 分半,接縫與換曲都用 WebAudio 交叉淡化。
